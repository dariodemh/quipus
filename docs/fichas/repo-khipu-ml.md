# Maria Contreras (2026). Khipu-ML — Structural Pattern Mining in Inka Khipus

- **Referencia:** preprint arXiv:2607.00185, "Structural Pattern Mining in Inka Khipus: Unsupervised Clustering, Provenance Classification, and a Computational Validation of the Santa Valley Match"; autora Maria Contreras (Universidad Peruana de Ciencias Aplicadas, UPC, Lima). Repositorio `mcontrerasmalpar-pixel/Khipu-ML`; licencia MIT; `CITATION.cff` fecha 2026-06-30. Commit fijado: `f832d3073e75a4443b42ad4d1ebe9f69a46cc188`. Notebook también en Kaggle (`macmaky/khipu-ml`).
- **Tipo / acceso:** preprint + repositorio de código (notebook + `src/`); texto completo (README, `notebooks/01_pipeline_khipu.ipynb`, `src/loader.py`, `features.py`, `utils.py`). El `khipu.db` no viene incluido (gitignored): hay que descargarlo del OKR.
- **Pregunta u objetivo:** minar patrones estructurales en khipus inka sin acceso físico a los objetos: (1) agrupar el corpus por estructura (clustering no supervisado), (2) clasificar procedencia a partir de features estructurales, (3) validar computacionalmente el hallazgo publicado de Medrano & Urton (2018) sobre la estructura de medades recto/verso en el valle de Santa.
- **Corpus y datos:** OKR — **619 khipus, 54,403 cuerdas, 110,677 nudos** (los mismos conteos que `khipu.db`). Se extraen 27 features estructurales por khipu. Subconjunto etiquetado para clasificación: la memoria dice 84.3 % de cobertura de la columna `REGION` (522 khipus) y clases con <10 muestras agrupadas como "Other"; el README habla de "135 labeled specimens" para las clases costeras. Caso Santa Valley: KH0323–KH0328 (de OKR, columna `ATTACHMENT_TYPE`).
- **Métodos:** ingeniería de features a partir de `cord`/`knot`/`ascher_cord_color` agregada por khipu (27 variables: n_cords, longitudes, niveles de jerarquía, twist S/Z, densidad y tipos de nudo S/L/E/LL/BL, entropía de color, etc.); reducción de dimensión con **UMAP** + clustering denso con **HDBSCAN** (sin fijar k); clasificación supervisada con **XGBoost** y validación cruzada estratificada 5-fold; interpretabilidad con **SHAP**; n-gramas de tipos de nudo como modelo secuencial; y validación R/V contando `ATTACHMENT_TYPE` = R/V por cuerdas pendant.
- **Hallazgos principales (con cifras):** (1) 3 clústeres estructurales, **silhouette = 0.769**. (2) Clasificación de estilo **Inka Late Horizon**: F1 = **0.86** en modelo afinado (0.80 sin afinar); el feature más discriminante según SHAP es la **dirección de torsión (twist)**; el imperio se caracteriza por S-twist (85.3 %), longitud corta uniforme, alta densidad de nudos y paleta de color restringida. (3) El clúster 2 (**160 khipus**) es "sesgo de colección colonial" (museos europeos/norteamericanos del s. XIX): la razón de torsión difiere del grueso de la Costa Central con p ≈ 3.7×10⁻²⁷⁶, en parte por torsiones no registradas codificadas `U`. (4) Clases costeras se confunden entre sí (**F1 ponderado 0.46** en 135 especímenes etiquetados) y los n-gramas de nudos no añaden señal (ΔF1 ≈ −0.006). (5) **Réplica Santa Valley**: con solo `ATTACHMENT_TYPE`, 5 de 6 khipus (KH0323–KH0328) son R o V puros; **KH0326 es el único mixto** (40 R / 69 V), el mismo que la study original señaló; el agregado R/V es **49 %/51 %** frente al ~47 %/53 % del trabajo original (KH0323: 310/0; KH0324: 0/54; KH0325: 0/207; KH0327: 0/93; KH0328: 56/0).
- **Afirmaciones sobre el significado o desciframiento y nivel de evidencia:** la réplica de Santa Valley "confirma el patrón **estructural** (recto/verso)" pero la propia autora aclara que **no** reproduce el total de tributo de 367 pesos, que requeriría decodificación posicional de los valores de nudo (trabajo futuro). Nivel: **apoyado con datos** para la estructura R/V (con el mismo khipu mixto que el original, lo que es una validación fuerte e independiente); **propuesto** para la interpretación de los clústeres (el clúster imperial y el sesgo de colección son lecturas plausibles, no significados del código). No hay desciframiento del contenido semántico.
- **Limitaciones y críticas:** reconocidas por la autora: el subconjunto etiquetado para clasificación geográfica es pequeño (135/619), lo que limita el rendimiento; sesgos de colección y de registro ligados al ensamblaje colonial del corpus; la réplica confirma solo el patrón estructural, no la contabilidad. Críticas mías: un **silhouette de 0.769** con HDBSCAN sobre 27 features y 619 objetos es llamativamente alto y merece auditoría (puede reflejar un eje de tamaño dominante más que "3 tipos" genuinos; conviene contrastar con submuestreo y con features estandarizadas). El F1 0.86 "Inka Late Horizon" procede de clases desbalanceadas y agrupadas; hay que verificar la partición CV y el solapamiento de khipus entre clases. No se publican los datos derivados ni las predicciones por khipu, lo que dificulta la réplica exacta (el notebook es el artefacto principal).
- **Relación con otros trabajos:** usa el OKR como única fuente; **replica y valida Medrano & Urton (2018)** (arena de Santa, hipótesis R/V = hanan/hurin) sin acceso físico; dialoga con la literatura de sesgo de colección. No usa el KFG ni el toolkit K-CAT, aunque converge con las conclusiones de K-CAT sobre sesgo de museo y sobre la dominancia de la torsión.
- **Relevancia para este proyecto:** pipeline completo y reutilizable (loader + features) y, sobre todo, un **protocolo de validación de una hipótesis publicada** sobre datos abiertos — exactamente el tipo de control que este proyecto necesita. Hipótesis comprobables: repetir el clustering con features estandarizadas y varias semillas; comprobar si el "clúster imperial" resiste al quitar khipus con twist `U`; verificar el agregado R/V y KH0326 con la base KDB/OKR. El resultado negativo de los n-gramas (ΔF1 ≈ −0.006) es un control útil contra el sobreajuste secuencial.
